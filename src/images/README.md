# Фотографии

Кладите файлы сюда, затем впишите имя файла в `data/*.json` и пересоберите.

Пример — портрет мастера в `data/site.json`:

```json
"about": {
  "photo": "mariya.webp",
  "photoAlt": "Мария, врач-косметолог, в кабинете"
}
```

Если поле пустое или содержит букву (`""`, `"b"`, `"c"`, `"d"`) — рисуется градиентная
заглушка нужного цвета. Как только появляется имя файла с расширением, подставляется фото
с ленивой загрузкой и заданными размерами.

## Куда что идёт

| Поле в данных                      | Пропорция | Рекомендуемый размер |
| ---------------------------------- | --------- | -------------------- |
| `site.json → hero.photo`           | 4:5       | 940×1175             |
| `site.json → about.photo`          | 4:5       | 600×750              |
| `site.json → education.photo`      | 16:11     | 900×620              |
| `site.json → gallery.photos[]`     | 1:1       | 900×900              |
| `procedures.json → photoCover`     | 16:10     | 1400×875             |
| `procedures.json → gallery[]`      | 4:3       | 600×450              |
| `procedures.json → stages[].photo` | 16:10     | 1000×625             |

## Обрезка

Фотография вписывается в окно нужной пропорции и обрезается от центра. Если важное
оказалось за краем, сместите точку обрезки полями `photoPos` (карточка)
и `photoDirPos` (таблица):

| Значение | Что остаётся видимым |
|---|---|
| `"center 22%"` | верхняя часть кадра — лицо не срежется сверху |
| `"center 50%"` | середина (так по умолчанию) |
| `"center 75%"` | нижняя часть |
| `"top"` / `"bottom"` | самый верх / низ |
| `"left center"` / `"right center"` | сдвиг по горизонтали |

Проценты подбираются на глаз: меняете число, `npm run build`, смотрите.

У направления два снимка: `photo` идёт в карточку блока «Что мы делаем» — она широкая
и низкая; `photoDir` — в таблицу «Направления и процедуры», там кадр вертикальный
во всю высоту блока. Если `photoDir` не заполнен, подставляется `photo`,
но обрезка будет грубее.

Формат — WebP, качество около 85. Подробности по съёмке: `docs/fotosemka-spisok-kadrov.md`
