# Estétique Beauty — сайт косметического кабинета

Статический сайт без зависимостей. Страницы собираются из файлов данных.

## Сборка

```bash
npm run build     # или: node build.mjs
```

Результат — в `dist/`. Открыть: `open dist/index.html`

## Где что менять

| Что | Файл |
|---|---|
| Услуги, цены, длительности, содержимое страниц процедур | `data/procedures.json` |
| Тексты главной, контакты, отзывы, курсы, вопросы | `data/site.json` |
| Оформление | `src/assets/site.css` |
| Поведение (меню, поп-ап, шторка, счётчики) | `src/assets/site.js` |
| Разметка и структура блоков | `build.mjs` |

После правки данных — пересобрать. Цена меняется в одном месте и обновляется
в карточке направления, таблице, мега-меню, на странице процедуры и в поп-апе записи.

## Структура

```
data/            исходные данные
src/assets/      стили и скрипты
build.mjs        сборщик
dist/            результат (перезаписывается при сборке)
docs/            спецификация и промт для разработки
```

## Что требует внимания

Процедуры с `"priceTodo": true` в `data/procedures.json` — цены проставлены
предположительно, их не было в исходном прайсе. Проверьте и уберите флаг.
Список выводится при каждой сборке.
