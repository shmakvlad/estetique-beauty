# Estétique Beauty — сайт косметического кабинета

Статический сайт без зависимостей. Страницы собираются из файлов данных.

## Команды

```bash
npm run build                    # собрать для просмотра с диска
npm run build:prod               # собрать для хостинга (чистые адреса)
npm run images                   # перевести новые фото в WebP
npm run where -- "текст"         # найти, из какого файла берётся текст
```

### Не знаете, где править?

```bash
npm run where -- "Записаться на консультацию"
```

Команда покажет файл и строку. Правите там — потом `npm run build`.

Результат — в `dist/`. Открыть: `open dist/index.html`

Порядок при добавлении фотографий: положить файлы в `src/images` →
`npm run images` → вписать имена в `data/*.json` → `npm run build`.

## Где что менять

| Что                                                     | Файл                                      |
| ------------------------------------------------------- | ----------------------------------------- |
| Услуги, цены, длительности, содержимое страниц процедур | `data/procedures.json`                    |
| Фото направления в карточке «Что мы делаем»             | `procedures.json → categories[].photo`    |
| Фото направления в таблице «Направления и процедуры»    | `procedures.json → categories[].photoDir` |
| Тексты главной, контакты, отзывы, курсы, вопросы        | `data/site.json`                          |
| Оформление                                              | `src/assets/site.css`                     |
| Поведение (меню, поп-ап, шторка, счётчики)              | `src/assets/site.js`                      |
| Разметка и структура блоков                             | `build.mjs`                               |

После правки данных — пересобрать. Цена меняется в одном месте и обновляется
в карточке направления, таблице, мега-меню, на странице процедуры и в поп-апе записи.

## Структура

```
data/            исходные данные — тексты, услуги, цены
src/assets/      стили и скрипты
src/images/      фотографии
build.mjs        сборщик
dist/            результат сборки — НЕ редактировать
docs/            спецификация, промт, список кадров для съёмки
```

### Про две папки с картинками

`src/images/` — куда кладёте файлы вы. `dist/images/` — копия, которую делает сборка.
То же со стилями: правите `src/assets/site.css`, копия попадает в `dist/assets/`.

Файлы в `dist` можно открывать и править вручную, но Prettier к ним не применяется —
папка перечислена в `.prettierignore`, иначе форматирование ломает вёрстку:
строчные элементы разрываются по строкам, и между ними появляются лишние пробелы.

**Правка внутри `dist` исчезнет при следующей сборке** — папка каждый раз стирается
и создаётся заново. Редактируйте только `data/`, `src/` и `build.mjs`.

Папка `dist` не хранится в git: она полностью восстанавливается из исходников,
а держать в истории копии фотографий незачем. На хостинг выкладывается именно она —
после `npm run build:prod`.

## Что требует внимания

Процедуры с `"priceTodo": true` в `data/procedures.json` — цены проставлены
предположительно, их не было в исходном прайсе. Проверьте и уберите флаг.
Список выводится при каждой сборке.
