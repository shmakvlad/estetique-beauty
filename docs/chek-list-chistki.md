# Чистки: что уточнить у Марии

Тексты пяти процедур написаны по стандартным протоколам. Ниже — всё, что я
проставил на своё усмотрение и что должен подтвердить специалист до публикации.

Файл с данными: `data/procedures.json`

---

## 1. Медицинская часть — только Мария

Это не вопрос стиля: ошибка в противопоказаниях касается здоровья клиента
и её профессиональной ответственности.

### Спорные места, на которые смотреть в первую очередь

| Процедура       | Что я написал                                                                 | Проверить                               |
| --------------- | ----------------------------------------------------------------------------- | --------------------------------------- |
| Детокс-очищение | Беременность **не** противопоказание, достаточно заменить активные компоненты | Так ли это в её протоколе               |
| Атравматичная   | Беременность и лактация **в противопоказаниях**                               | Не противоречит ли предыдущему пункту   |
| Ультразвуковая  | Эпилепсия, кардиостимулятор, металлические импланты                           | Полный ли список аппаратных ограничений |
| Комбинированная | Те же аппаратные ограничения плюс купероз                                     | То же                                   |
| Все пять        | Приём изотретиноина и ретиноидов внутрь                                       | Срок отмены до процедуры                |

### По каждой процедуре

- **Показания** — по 6 пунктов. Верно ли, нет ли лишних и чего не хватает
- **Противопоказания** — по 6–7 пунктов
- **Этапы** — по 4 на процедуру. Совпадают ли с тем, как она реально работает
- **Подготовка и уход после** — сроки отмены кислот, солнца, сауны, SPF

## 2. Цифры, которые я поставил по среднему

Ни одно из этих значений не было в исходном прайсе.

| Процедура         | Курс              | Периодичность    | Эффект                | Восстановление              |
| ----------------- | ----------------- | ---------------- | --------------------- | --------------------------- |
| Глубокое очищение | 4–6 процедур      | раз в 1–2 месяца | до 2 месяцев          | не требуется                |
| Детокс-очищение   | 4–6 процедур      | раз в 3–4 недели | до 1 месяца           | не требуется                |
| Комбинированная   | 3–4 процедуры     | раз в 1–2 месяца | до 6 недель           | до суток лёгкое покраснение |
| Ультразвуковая    | по состоянию кожи | раз в 2–4 недели | до 3 недель           | не требуется                |
| Атравматичная     | 4–6 процедур      | раз в 2–3 недели | накопительный, курсом | не требуется                |

Эти значения видны на странице в панели с ценой — то есть человек на них рассчитывает.

## 3. Цена

**Атравматичная чистка — 130 BYN.** Цену придумал я: этой процедуры не было
в исходном прайсе, но она была перечислена в списке услуг. В данных стоит пометка
`"priceTodo": true`, сборка выводит её при каждом запуске.

После уточнения — поправить `price` и удалить строку с пометкой.

Заодно проверить, все ли чистки перечислены. Сейчас пять:
глубокое очищение, детокс, комбинированная, ультразвуковая, атравматичная.

## 4. Косметика

У всех пяти процедур в панели указано **Ultraceuticals**. Для глубокого очищения
это из вашего описания, для остальных я поставил по аналогии.

Уточнить: на чём реально идут ультразвуковая, атравматичная и детокс. Если бренды
разные — это плюс, а не минус: покажет, что средства подбираются под задачу.

## 6. Куда вносить

Всё в `data/procedures.json`, каждая процедура — отдельный блок:

```json
{
  "slug": "atravmatichnaya-chistka",
  "price": 130,              ← поправить
  "priceTodo": true,         ← удалить строку после уточнения
  "specs": [ ... ],          ← курс, периодичность, эффект, восстановление
  "indications": [ ... ],    ← показания
  "contraindications": [ ... ],
  "prepare": [ ... ],
  "aftercare": [ ... ],
  "photoCover": "",          ← имя файла обложки
  "stages": [ { "photo": "" } ]
}
```

После правок: `npm run build`

Не знаете, где лежит конкретная фраза, — `npm run where -- "часть текста"`
